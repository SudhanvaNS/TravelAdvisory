# Nearby Restaurants and Hotels Finder
This is a React-based web application that fetches data on nearby restaurants and hotels using the RapidAPI and displays them on a webpage. The application leverages various React components and Material-UI for a responsive and interactive user interface.

# Features
#### Dynamic Location Detection: Automatically detects the user's current location using the browser's Geolocation API.
#### Interactive Map: Displays nearby restaurants and hotels on an interactive map, allowing users to explore their surroundings visually.
#### Filter by Rating: Users can filter places based on their ratings.
#### Responsive UI: The application is fully responsive, ensuring a seamless experience across different devices.
#### Type Selection: Users can switch between viewing restaurants and hotels.

## Technologies Used
#### React: A JavaScript library for building user interfaces.
#### Material-UI: React components for faster and easier web development.
#### RapidAPI: Fetches data on nearby places such as restaurants and hotels.
#### Geolocation API: Automatically determines the user's location.

## Usage

Once the application is running:
#### The application will automatically detect your location and display nearby restaurants or hotels.
#### Use the filter options to refine the search based on rating or type.
#### Click on any listed place to see its location on the map.
